2. 자동으로 다루는 정보

  • 접속 IP: 요청 폭주를 막고(IP별 요청 수 제한), 한 사람이 여러 계정으로 랭크전을 짜고 치는 걸 막는 데만 쓴다. 게임 서버 메모리에서 해시로만 비교하고 저장하지 않는다.
  • 서버 기록: 사람이 칠 수 없는 속도로 문장을 완료하면 방 코드·내부 계정 번호·닉네임이 서버 로그에 남는다. Cloudflare가 정한 로그 보관 기간이 지나면 자동으로 지워진다. 호스팅 업체(Cloudflare)도 서비스 운영을 위해 접속 기록을 처리한다.
  • 브라우저 저장소: 로그인 상태, 닉네임, 소리·테마·언어 설정을 이 브라우저에만 저장한다. 쿠키는 쓰지 않는다.

4. 탈퇴와 삭제

로그인한 상태에서 메뉴 위쪽의 탈퇴를 누르면 계정과 위 1번의 기록을 바로 모두 지운다. 되돌릴 수 없다. 카카오 쪽 연결은 카카오 계정 설정의 연결된 서비스 관리에서 끊을 수 있다.

열람·정정·삭제·처리정지를 요청하거나 궁금한 게 있으면 GitHub 이슈로 알려 달라. 제재된 계정의 삭제도 여기로 요청하면 된다.

5. 안전하게 다루는 방법

  • 로그인 세션은 원래 값 대신 해시만 저장한다. 데이터베이스가 새도 그대로 쓸 수 없다.
  • 게임 화면은 같은 주소의 스크립트만 실행하도록 막아 두었다(Content-Security-Policy).
  • 계정 하나에 살아 있는 로그인은 최근 5개만 남기고, 로그아웃하면 모든 기기에서 나간다.
